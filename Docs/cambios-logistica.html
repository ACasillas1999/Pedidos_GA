Resumen ejecutivo

La plataforma centraliza pedidos, rutas, choferes, vehiculos, servicios, gasolina, inventario, reportes y aplicacion movil. Las mejoras recientes refuerzan trazabilidad (validaciones y precios por factura), productividad (optimizacion de rutas, drag & drop, tableros), visibilidad (filtros avanzados, dashboards, mapa de calor, estadisticas de inventario) y comunicacion (notificaciones WhatsApp). Se agregaron flujos completos de gasolina con importacion masiva, tablero de servicios drag & drop que impacta inventario, controles de observaciones, y mejoras en la app movil (kilometraje obligatorio, condiciones del vehiculo, restriccion por version y vehiculo asignado).

Tecnologias utilizadas

  • Backend: PHP 7+ (scripts y endpoints por modulo), MySQL/MariaDB.
  • Frontend: HTML5, CSS (styles*.css), JavaScript (DOM, AJAX).
  • Mensajeria: WhatsApp (Mensajes_WP/*, Mensaje_WP.php).
  • Mapas/geo: mini mapa, calculo y visualizacion de distancias (update_distance.php, api_mapa_datos.php, mapa_calor.php).
  • Exportes: Excel (export_reporte_precios.php, reporte_precios_facturas.php).
  • Sesion y seguridad: check_session.php, logout.php, validaciones de asignacion y version en app.

Arquitectura del sistema

  • Modelo: Aplicacion web PHP modular (paginas autocontenidas + endpoints AJAX + app movil que consume endpoints dedicados).
  • Capas:
    • Presentacion: vistas PHP/HTML con JS y CSS por pagina.
    • Logica de negocio: scripts por dominio (pedidos, rutas, vehiculos, choferes, servicios, inventario, gasolina, reportes).
    • Integraciones: WhatsApp, Excel, mapas/geo.
    • Datos: MySQL via conexiones compartidas (Conexiones/Conexion.php, App/Conexiones/Conexion.php).
  • Navegacion: Sidebar con acordeones (pedidos/rutas, vehiculos/choferes, servicios/gasolina/inventario, estadisticas/reportes, app).

Flujos principales (resumidos)

  • Alta de pedido: datos + multiples facturas y precio + coordenada en mini mapa -> validar -> asignar chofer (WhatsApp) -> agrupar en ruta -> optimizar/ordenar (drag & drop) -> seguimiento y estadisticas.
  • Gestion de rutas: crear grupos -> desactivar/separar por factura si aplica -> optimizar -> ajustar orden manual -> guardar/publicar.
  • Vehiculos/choferes: alta/edicion -> asignacion por ubicacion -> registro kilometraje/servicio/gasolina -> historicos y observaciones.
  • Servicios/gasolina/inventario: alta y registro -> impacto en inventario (cuando servicio pasa a programado) -> observaciones -> estadisticas.
  • Reporte de precios: filtrar fecha/sucursal/vendedor -> detectar <1000 y correcciones -> pendientes -> exportar Excel.
  • Mapa de calor: filtros -> zona y tamano -> resumen para decisiones de cobertura.
  • App movil: validar version/vehiculo/kilometraje -> checklist de condiciones -> gestionar rutas y facturas -> exportar a Google Maps.

Documentacion por modulo y cambios

1. Funcionalidad global

  • Notificacion automatica via WhatsApp al asignar pedido: al confirmar asignacion se envia mensaje con datos clave al chofer usando Mensajes_WP/*; reduce llamadas y asegura acuse.
  • Sidebar con acordeones: accesos agrupados por dominio (pedidos/rutas, vehiculos/choferes, servicios/inventario, reportes, app) para menor scroll y acceso rapido.

2. Pedidos GA (Inicio)

  • Barra de filtrado actualizada: filtros por fecha, estado, sucursal, tipo; combinables sin recargar la pagina.
  • Boton de descarga de la aplicacion: enlace directo a instalador/tienda para choferes y operadores.
  • Guia de pedidos generada: ayuda contextual sobre estados, acciones y filtros.
  • Columna Precio Factura: visibilidad del monto facturado en listado para control y conciliacion.
  • Asignacion de grupo para generar ruta: permite armar grupos con prioridad y orden de trabajo.
  • Seleccion de grupos para mostrar ruta: elegir que grupos se proyectan en mapa/listado para enfocar operaciones.

3. Detalles de ruta

  • Desactivar grupo (separar por factura): pausa o divide grupos cuando las facturas requieren tratamiento individual.
  • Optimizacion de ruta: orden sugerido para minimizar distancia/tiempo con los puntos del grupo activo.
  • Drag and drop de prioridad: ajuste manual del orden propuesto.

4. Agregar pedido

  • Multiples facturas por pedido en un solo formulario.
  • Campo de precio: registra monto facturado y alimenta columnas/reportes.
  • Coordenada destino desde mini mapa: seleccion guiada de lat/long para evitar errores.

5. Detalles del pedido

  • Nuevo campo Precio Factura: validacion visual y control de discrepancias.

6. Actualizar pedido

  • Checkbox de Validar: control de calidad (datos completos, precio, coordenadas).
  • Bloqueo de asignacion de chofer si no esta validado.

7. Estadisticas

  • Filtro de rango de fecha actualizado: recalcula KPIs y graficos.
  • Contenedores redisenados: bloques mas legibles para indicadores.

8. Mapa de Calor

  • Filtro de rango de fecha, tipo de pedido y sucursal.
  • Seleccion de zona de mapa y tamano (km).
  • Resumen general de la zona: totales y concentraciones.

9. Reporte de precios

  • Filtrado por rango de fecha, sucursal y vendedor.
  • Resumen general y pedidos menores a 1000 como alerta.
  • Correccion de precio (a favor/en contra) y estadisticas por vendedor.
  • Pedidos pendientes (atrasados) y exportar en Excel con filtros aplicados.

10. Vehiculos (Inicio)

  • Dashboard por razon social y ubicacion fisica.
  • Gestion de choferes por ubicacion fisica.
  • Asignacion/Designacion/Cambio de vehiculo a chofer.

11. Detalles de vehiculo

  • Informacion general (ficha de unidad).
  • Kilometraje proximo servicio.
  • Asignacion de sucursal y chofer.
  • Registro de kilometraje, servicio y gasolina.
  • Historial de kilometraje y de conductores.
  • Observaciones.
  • Gasolina y Servicios: consumo y trabajos realizados.

12. Detalles de Chofer

  • Editar chofer.
  • Acceso directo a WhatsApp o llamada.
  • Resumen por rango de fecha de pedidos.
  • Pedidos recientes y vehiculo asignado (resumen).
  • Historial de vehiculos y observaciones acumuladas.
  • Contacto centralizado.

13. Gas (Gasolina)

  • Filtrado por rango de fecha o mensual.
  • Registro de gasolina por vehiculo y fecha.
  • Historial de importacion y pendientes de alta cuando faltan vehiculos.
  • Descarga de machote e importacion masiva (obligatorio usar formato); exporte de reporte filtrado.
  • Requisito: los vehiculos deben existir para mover registros de pendientes a activos.

14. Servicios

  • Tablero drag and drop por estatus y vista en lista.
  • Filtrado por fecha.
  • Impacto en inventario solo cuando el servicio pasa a programado.
  • Vehiculo en taller: deshabilitado hasta cambiar estatus.
  • Modal para agregar servicio a un vehiculo.

15. Agregar Servicio

  • Listado de servicios disponibles con editar/eliminar.
  • Alta de servicio: nombre, materiales requeridos y vehiculos aplicables.
  • Control de materiales para descuento al programar/ejecutar.

16. Observaciones

  • Registro de incidencias de choferes; pueden originar servicios.
  • Filtro por tipo de observacion.
  • Historial de resultas: tipos de servicios generados y tiempos de resolucion.

17. Inventario

  • Listado de materiales en stock con editar/ajustar/eliminar.
  • Filtros por tipo de stock y sucursal.
  • Alta de producto: datos esenciales y vehiculos aplicables.

18. Estadisticas de inventario

  • KPIs por rango de fechas seleccionado.
  • Top de material con stock bajo.
  • Top de material con mayor valor.
  • Estadisticas generales (consumos, entradas, ajustes).

19. Aplicacion movil

  • Modal obligatorio de kilometraje y formulario de condiciones.
  • Genera servicio si el kilometraje supera el umbral.
  • Agrupacion de facturas, gestion de mapa de ruta y exportar ruta a Google Maps.
  • Modulo de vehiculo y gestion de formulario del vehiculo.
  • Conserva sesion y maneja excepciones de conexion.
  • Actualizacion por API REST; restriccion si la version no es vigente.
  • Restricciones si no tiene vehiculo asignado, kilometraje o formulario de condiciones.

Casos de uso (ejemplos)

  • Asignar pedido a chofer con notificacion: operador valida -> asigna chofer -> sistema envia WhatsApp con datos clave -> chofer confirma.
  • Optimizar y priorizar ruta: supervisor agrupa pedidos -> optimiza -> ajusta orden con drag & drop -> guarda -> chofer sigue prioridad.
  • Alta de pedido con multiples facturas: ingresa datos -> agrega facturas y precio -> selecciona coordenada -> guarda -> listo para asignacion.
  • Reporte de precios: filtra por fecha/sucursal/vendedor -> revisa pedidos < 1000 y correcciones -> marca pendientes -> exporta Excel.
  • Control de gasolina: importa masivo con machote -> revisa pendientes por vehiculos faltantes -> sincroniza -> exporta reporte filtrado.
  • Servicios e inventario: mueve servicio a programado -> inventario descuenta materiales -> vehiculo en taller queda bloqueado -> se libera al cerrar.
  • App movil: chofer valida version y vehiculo -> captura kilometraje y condiciones -> si excede umbral, se genera servicio -> sigue ruta y exporta a Google Maps.

Recomendaciones finales

  • Validar pedidos antes de asignar chofer y registrar cambios de precio con trazabilidad.
  • Monitorear integraciones de WhatsApp y exportes Excel para asegurar entregabilidad y formato.
  • Capacitar usuarios en filtros (fecha, sucursal, tipo) y en priorizacion de rutas con drag & drop.
  • Programar mantenimientos preventivos segun kilometraje proximo servicio y consumos de gasolina.
  • Mantener catalogo de vehiculos sincronizado antes de importaciones masivas de gasolina.
  • Supervisar tablero de servicios e inventario para evitar desabasto y vehiculos inmovilizados.
  • En la app movil, reforzar cumplimiento de version, vehiculo asignado y kilometraje para garantizar datos completos.
